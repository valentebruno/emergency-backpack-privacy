# Emergency Backpack — Privacy Policy

Public privacy policies for Emergency Backpack, served at
https://valentebruno.github.io/emergency-backpack-privacy/ (iOS) and
https://valentebruno.github.io/emergency-backpack-privacy/android.html (Android and Wear OS)

The page is generated from the app's own in-app policy text (six languages) by
`scripts/privacy_page.py` in the app repository; edit it there, not here.

`android.html` is generated from the Android app's in-app policy text by `tools/privacy_page.py` in the
EmergencyBackPackAndroid repository.
